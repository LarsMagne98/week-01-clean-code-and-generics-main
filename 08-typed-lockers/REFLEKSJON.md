## Testlogg

| Inndata eller handling | Forventet resultat | Faktisk resultat |
| ---------------------- | ------------------ | ---------------- |
| ny text "Beacon"       | Beacon             | Beacon           |
| ny number 42           | 42                 | 42               |
| text.Replace("Relay")  | Relay              | Relay            |
| number.Replace(99)     | 99                 | 99               |

## Forklaring

Hva er forskjellen mellom typeargumentet int og konstruktørargumentet 42?

Mitt svar:
Typeargumentet forteller hvilken type verdier den skal inneholde, konstruktørargumentet 42 er den konkrete verdien den holder.
